# canvas-basketball-game

A simple basketball coaching and team management game.

## Stack

- Electron + React + TypeScript + Vite (`electron-vite`)
- HTML Canvas overhead court view

## Features

- Manage lineup and ratings, play a short season
- Watch AI vs AI games (pause / 1x / 2x / 4x) or sim results
- Career save/load via Electron (`userData/career.json`)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
